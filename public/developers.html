ChatGPT integration

ChatGPT에 Quilo 연결

원격 MCP는 Quilo 로그인과 OAuth 2.1 + PKCE를 사용합니다. 액세스 토큰을 대화창에 붙여 넣지 않아도 되고, 연결할 때 권한을 직접 확인합니다.

Remote MCP URL  https://quilolab.com/mcp
OAuth metadata  https://quilolab.com/.well-known/oauth-protected-resource/mcp
  1. ChatGPT 설정의 Security and login에서 Developer Mode를 켭니다.
  2. Plugins에서 새 개발자 앱을 추가하고 위 Remote MCP URL을 입력합니다.
  3. Quilo 로그인 후 권한 화면에서 연결을 허용합니다.

로컬 플러그인에 연결

발급한 토큰을 로컬 자격 증명 파일에 저장하면 Quilo 플러그인이 계정·작업·파일 도구를 활성화합니다. 파일 업로드·다운로드는 명시한 폴더 안에서만 허용됩니다.

node ~/plugins/quilo/scripts/configure.mjs 'quilo_live_...'
export QUILO_UPLOAD_ROOTS="$HOME/Downloads:$HOME/Documents/Quilo"
codex plugin add quilo@personal

새로운 Codex task를 열어 “Quilo에서 내가 쓸 수 있는 기능 찾아줘”라고 말해보세요.
