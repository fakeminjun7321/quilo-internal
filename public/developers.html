02

ChatGPT에 연결

원격 MCP는 Quilo 로그인과 OAuth 2.1 + PKCE를 사용합니다. 토큰을 대화창에 붙여 넣지 않습니다.

  1. ChatGPT 설정의 Security and login에서 Developer Mode를 켭니다.
  2. Plugins에서 새 개발자 앱을 추가합니다.
  3. 아래 Remote MCP URL을 입력하고 Quilo 권한 화면에서 연결을 허용합니다.
ChatGPT Plugins 열기 공식 연결 가이드
Remote MCP URL https://quilolab.com/mcp
03

API v1

브라우저 쿠키를 복사하지 않고 범위가 제한된 Bearer 토큰으로 요청합니다.

인증

모든 계정 API 요청의 Authorization 헤더에 토큰을 포함합니다.

Request header Authorization: Bearer YOUR_ACCESS_TOKEN

주요 엔드포인트

GET/api/catalog기능 목록
GET/api/openapi.jsonOpenAPI 스키마
GET/api/v1/account계정 정보
GET/api/v1/jobs작업 목록
GET/api/v1/files파일 목록
POST/api/v1/reports보고서 생성
