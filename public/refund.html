환불정책

시행일: 2026년 5월 1일

1. 기본 원칙

크레딧은 보고서 초안 생성 기능 이용을 위한 선불 이용권입니다. 생성 요청 전에는 사용자가 생성을 취소할 수 있으며, 생성이 완료되지 않은 실패 작업에는 원칙적으로 크레딧을 차감하지 않습니다.

2. 환불 가능 사례

  • 서비스 오류로 보고서 파일이 생성되지 않았는데 크레딧이 차감된 경우
  • 중복 차감, 관리자 입력 실수, 충전 오류가 확인된 경우
  • 사용하지 않은 크레딧에 대해 운영자가 환불 가능하다고 인정한 경우

3. 환불이 제한될 수 있는 사례

  • 보고서 파일이 정상 생성·다운로드 가능한 상태로 제공된 경우
  • AI 결과의 문체, 분량, 평가 만족도 등 주관적 사유만 있는 경우
  • 사용자가 잘못된 파일을 업로드했거나 학교 규정에 맞지 않게 사용한 경우
  • 금지 행위, 계정 공유, 권한 없는 자료 업로드가 확인된 경우

4. 환불 요청 방법

환불 요청 시 사용자 이름, 생성 시각, 보고서 종류, 오류 내용, 결제·충전 내역을 계정 발급자 또는 서비스 운영자에게 알려주세요. 운영자는 사용 로그와 파일 생성 여부를 확인해 환불 또는 크레딧 복구 여부를 안내합니다.

5. 청약철회와 유료 판매 고지

유료 크레딧을 반복적으로 판매하거나 공개적으로 모집하는 경우 전자상거래 관련 법령상 사업자 정보 표시, 통신판매업 신고, 청약철회, 세금 처리 등 별도 의무가 발생할 수 있습니다. 정식 유료 판매 전에는 해당 정보를 별도 고지합니다.
