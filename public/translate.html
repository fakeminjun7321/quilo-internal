PDF 통번역 Max

PDF를 올리면 그림·표·레이아웃을 최대한 보존하며 텍스트를 한국어로 바꿔 PDF로 돌려줍니다. 번역 제공자 및 서버에 설정된 OCR 제공자에 추출 텍스트가 전송되며, 재조판·OCR에서는 PDF 또는 페이지 이미지가 전송될 수 있습니다.

번역할 PDF *
📄 PDF를 끌어다 놓거나 클릭 (여러 개 가능) 일반 PDF · 스캔본/이미지 PDF 모두 지원 (스캔본은 자동 OCR) · 여러 파일은 순서대로 번역 후 파일별 다운로드

PDF만 올리면 됩니다 — 일반 문서는 ‘빠른 번역’, 스캔본·수식 많은 문서는 ‘재조판’을 권유합니다(진행 전에 한 번 더 여쭤봐요). 원하면 직접 고를 수도 있어요.

잘 되는 것
  • 일반 문서: 레이아웃·그림 그대로 두고 글자만 한국어로(빠른 번역).
  • 수식 많은 논문: 다시 조판하며 깨진 수식을 정준형으로 복원(재조판). 본문 속 그림·그래프도 원본을 잘라 제자리에 복원합니다.
  • 2단 논문은 2단 구조를 유지하며 재조판합니다(읽기 순서 좌→우 자동 보정).
  • 스캔본·이미지 PDF: 자동 OCR 후 재조판 — 원본 그림도 잘라 복원.
  • 긴 문서는 구간을 나눠 병렬로 빠르게 처리합니다.
  • 여러 PDF를 한 번에: 파일을 여러 개 선택하면(최대 10개) 순서대로 번역하고, 끝난 파일부터 바로 내려받을 수 있습니다(2개씩 겹쳐 처리).
아직 안 되거나 제한되는 것
  • 긴 스캔본도 OK — 구간으로 나눠 자동 OCR 재조판 후 합칩니다. 사진 위에 숨은 OCR 텍스트가 심긴 스캔(vFlat 등)도 자동 감지해 재조판으로 처리합니다.
  • 3단 이상이거나 본문·표가 불규칙하게 섞인 레이아웃은 단순화될 수 있습니다(2단까지는 유지).
  • 그래프·표가 이미지로 박힌 경우 그 안의 글자·축 라벨은 번역되지 않습니다.
  • 스캔본의 그림 위치가 가끔 살짝 어긋날 수 있습니다.
  • 손글씨, 암호 걸린 PDF, 한국어 외 다른 언어로의 번역은 지원하지 않습니다.

결과물은 24시간 동안 다시 내려받을 수 있습니다(이 기기 기준).
