# Quilo launch film brief

- **Mode:** autonomous preparation
- **Purpose:** product launch / trust-building promo for Quilo
- **Destination:** website hero, YouTube, and presentation embed
- **Format:** 1920×1080, 16:9
- **Target duration:** approximately 45 seconds
- **Language:** Korean narration with restrained English product phrases
- **Audience:** students and early university users doing demanding research, report, translation, and analysis work
- **Angle:** Demo Loop — the product is easiest to trust when the actual workflow visibly completes end to end
- **Message:** Quilo turns a question and scattered source files into an analyzed, structured result in one continuous workspace.
- **Visual rule:** native HTML UI reconstruction only; no slideshow of screenshots or generic stock imagery
- **Audio direction:** calm Korean narration, restrained electronic pulse, tactile typing/upload/connection/export SFX
- **Render status:** intentionally not rendered; this phase stops at storyboard, script, and asset preparation

## Receipts

- The 16:9 format follows the requested desktop advertising-film treatment and the website/YouTube destination.
- Forty-five seconds gives enough time for a complete input → analysis → graph → report story without turning into a feature catalogue.
- Demo Loop is selected because the requested visual language is typing, file motion, analysis links, generated charts/documents, and camera travel through the working surface.
